Telnet Protocol

Remote Login Protocol

What is Telnet?

Telnet is a network protocol used to remotely access another computer over a TCP/IP network. It allows users to log in and execute commands on a remote system.

Features

  • Remote login
  • Command-line access
  • Uses TCP Port 23
  • Simple text-based communication

Advantages

  • Easy to use
  • Useful for network testing
  • Lightweight protocol

Disadvantages

  • No encryption
  • Passwords are sent in plain text
  • Not secure for modern networks

Example Command

telnet 192.168.1.10 23
